# ゲームシステム仕様

## 基本ループ

ゲームは `playing`、`upgrade`、`gameover` の3状態で進行します。戦闘中は移動、敵侵入、標的選択、発射、投射物、ドロップ、経験値の更新を続けます。経験値が必要量へ達すると世界の更新を停止してアップグレード選択へ移り、選択後に戦闘を再開します。体力が0になるとゲームオーバーとなり、リザルトを表示します。

| 状態 | 役割 | 主なUI |
| --- | --- | --- |
| `playing` | 戦闘、敵侵入、ドロップ回収、時間計測。 | HUD、フローティング仮想スティック、武器レール。 |
| `upgrade` | 3択の強化選択と、1ラン3回までの再抽選。 | 強化コンソール。 |
| `gameover` | 戦闘を停止し、最終統計を確定。 | リザルト、再出撃。 |

## 攻撃とダメージ計上

初期武器3種と25モジュールは、それぞれTier 1〜3を持ちます。各攻撃はダメージ発生源IDを保持し、実際に敵HPから減ったダメージのみを集計します。敵が確定撃破された時点で、最後にダメージを与えた攻撃へ撃破数を記録します。

> この方式により、投射物、設置物、状態異常、反撃波、周回攻撃などの遅延・継続効果も、リザルトへ正しい発生源で反映されます。

### 標準強化

| 名称 | 役割 |
| --- | --- |
| レール増幅器 | レールパルスの出力を強化。 |
| 散弾アレイ | 近距離向けの三連散弾を追加・強化。 |
| 周回センチネル | 接近敵を処理する周回攻撃を追加・強化。 |
| フラックス中継機 | 射撃間隔と移動機構を調整。 |
| 防壁コア | 装甲を再構成して耐久を回復。 |

### モジュールカタログ

| 系統 | モジュール |
| --- | --- |
| 直線・貫通 | ベクターランス、跳弾バースト、迫撃アーク、プリズム分裂、イオンランス、ニードルレイン、クラスターコア。 |
| 範囲・斬撃 | ノヴァリング、リターンブレード、近接地雷、プリズム扇撃、位相クリーヴァー、ソーハロ、ソニックブレイカー。 |
| 追尾・連鎖 | ミラージュドローン、アーク連鎖、サーマルアーク、チェーンハープーン。 |
| 設置・制御 | セントリーパイロン、特異点弾、デコイビーコン、スカイフォール標識。 |
| 防御・状態 | リアクティブ装甲、クライオロック、腐食刻印。 |

モジュールのDPS比較、設置系の補正履歴、Tier別の詳細は[モジュールDPS報告](../module_dps_report.md)を参照してください。

## 敵、侵入、当たり判定

敵はScout、Striker、Bulwarkの基本3種で構成されます。生成時は封鎖壁の外側に置かれ、`enteringContainment` 状態の間は高速で戦闘領域へ侵入します。壁の内側へ到達した時点で侵入状態を解除し、共通の戦闘対象判定へ入ります。

| ルール | 実装上の意図 |
| --- | --- |
| 壁外侵入中は対象外 | 画面外・壁外の敵を倒して回収不能なドロップが生じる問題を防ぐ。 |
| 壁内で共通対象判定 | 標準武器・全モジュールの命中条件を統一する。 |
| 水平実寸に沿う当たり判定 | 拡大ボスも見た目に近い攻撃、接触、突進の判定を持つ。 |
| Bulwarkだけが撃破爆発 | 通常敵の撃破で不意なプレイヤーダメージが発生しないようにする。 |

プレイヤーは移動可能領域内に制限され、アリーナ内の6個の障害物を円形衝突判定で通り抜けられません。停止を5秒続けると、赤白点滅の予告後に落下針が出現し、触れていると20ダメージを受けます。

## 成長、報酬、周期ボス

通常のレベルアップはランダム3択です。Lv30からは7Lvごとに新規モジュール候補を優先して武器枠を増やします。Lv50以降は成長の急加速を防ぐため、経験値流入と回復・マグネット報酬を抑え、必要経験値を追加成長させます。

巨大ボスは5Lvごとに1体だけ生成します。出現個体の見た目を2倍へ拡大し、HPはその時点のオレンジのタンク（Bulwark）基準値の20倍です。討伐時は最大HP+3、1Lv上昇、全回復、通常の強化選択を提供します。

高レベル敵変種はLv40、Lv50、Lv60で各7種を解放し、出現割合を30%、40%、50%へ上げます。凍結・腐食・デコイをテーマとする敵変種は含めません。詳細な数値は[高レベル変種パラメータ](../high_level_variant_parameters.md)を参照してください。

## ドロップとリザルト

回復アイテムとマグネットは敵撃破時に確率で生成され、寿命が近づくと点滅して消滅します。マグネットは画面内の経験値ジェムを一括回収します。レベル帯ごとの確率と回復量は[高レベル帯バランス報告](../high_level_balance_report.md)を正とします。

リザルト画面は次の項目を表示します。

| 総合項目 | 装備別項目 |
| --- | --- |
| 生存時間、総撃破数、総与ダメージ、最終レベル。 | 取得済み攻撃のTier、実与ダメージ、最終撃破数。 |

新しいランまたは再出撃時には、全ての戦闘統計を初期化します。
