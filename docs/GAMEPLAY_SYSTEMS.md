# ゲームシステム仕様

## 出撃開始とモード

ゲームは開始画面から始まります。オペレーター名を入力し、NormalまたはEndlessを選んで出撃します。名前、プレイヤー設定、Normal／Endless別のベストスコアは端末のローカルストレージへ保存します。

| モード | 目的 | ボス |
| --- | --- | --- |
| Normal | 10:00で完結する固定任務。時間内の最終ボス撃破でクリア、未撃破で失敗。 | 3:00に侵入母艦、6:00に突撃指揮機、9:15に重装破城機。 |
| Endless | 固定終了時刻を持たず、生存時間とスコアを伸ばす。 | 5Lvごとに巨大ボス。Lv40、Lv50、Lv60で高レベル変種セットを順次解放。 |

Normalの敵生成は段階式プロファイルと編成ディレクターを使います。同時通常敵は最大56体、生成速度は最大4体/秒、1回の生成は最大2体です。ディレクターは高速侵入、正面突破、精鋭部隊、大群の編成をキューへ積み、単純な独立抽選だけでは作れない戦闘のまとまりを作ります。ボス出現時は既存の通常敵を整理し、ボス中の通常生成を停止します。

未回収XPジェムは100メッシュを上限とし、上限到達後のXPは既存ジェムへ統合します。Normalの高レベル変種率は最大35%、直接ダメージを持つ波動変種は同時3体までです。Endlessは既存のレベル駆動スポーンとLv40／50／60の30%／40%／50%変種率を維持します。

## 状態遷移

ゲーム内ワールドは次の5状態を持ちます。開始画面とチュートリアルはReact側で管理し、ラン開始後にワールドを生成します。

| 状態 | 役割 | 主なUI |
| --- | --- | --- |
| `playing` | 戦闘、敵侵入、ドロップ回収、Dodge、時間計測。 | HUD、仮想スティック、Dodge、装備レール。 |
| `paused` | 手動PauseまたはSettings中に世界と時計を停止。 | PauseまたはSettingsダイアログ。 |
| `upgrade` | 3択の強化選択と、1ラン3回までの再抽選。 | 強化コンソール。 |
| `bossReward` | ボス撃破後の修復・増幅・改造選択。 | ボス報酬コンソール。 |
| `gameover` | Clear、Failed、Retiredの結果と統計を確定。 | 拡張リザルト、再挑戦、タイトル復帰。 |

`paused`、`upgrade`、`bossReward`、`gameover`ではゲームループの戦闘更新を進めません。ボス報酬を1つ決めると、その効果だけを適用して戦闘へ戻ります。

## 移動、Dodge、危険表示

プレイヤーは移動可能領域内に制限され、アリーナ内の6個の障害物を円形衝突判定で通り抜けられません。デスクトップはWASD／矢印キー、タッチ端末は任意位置から出るフローティングスティックを使います。

Dodgeの実装値は次のとおりです。

| 項目 | 値 |
| --- | ---: |
| クールダウン | 4.2秒 |
| 無敵時間 | 0.28秒 |
| 完全回避受付 | 予告終了前0.34秒 |
| 移動距離 | 3.4 |

デスクトップは`Space`、タッチ端末は画面上の`DODGE`ボタンで発動します。入力がない場合は直前の移動方向を使います。予告終了直前に攻撃線・攻撃範囲から抜けた場合、または無敵中に被弾判定を受けた場合にPerfect Dodgeが成立し、被ダメージを無効化して+200点、2.5秒間の攻撃+15%を得ます。ボスに対するPerfect Dodgeはボス行動を中断し、短い脆弱時間も作ります。

2秒停止後に50ダメージを与えていた落下針は通常プレイから廃止しました。`?idle`を付けたデバッグ・演出確認時だけ更新します。

敵の警告、突進、波動、砲撃、撃破爆発は赤系で統一します。プレイヤーの投射物、設置物、支援、回復は非赤系を使います。HP25%以下ではHUDを低耐久表示へ切り替えます。

## 攻撃、補助、対象選択

初期攻撃はレールパルス1つです。散弾アレイ、周回センチネルと25モジュールはアップグレードで取得します。実際に敵HPから減ったダメージだけを発生源別に集計し、撃破時は最後にダメージを与えた攻撃へ撃破数を記録します。

| 枠 | 上限 | 対象 |
| --- | ---: | --- |
| 攻撃 | 6 | 初期Railを含む。Scatter、Orbit、直接攻撃・設置攻撃モジュール。 |
| 補助 | 4 | Relay、Barrier、Reactive、Cryo、Corrosion。 |

攻撃は原則Tier 3、RelayとBarrierはTier 4を上限とします。枠が埋まると未取得の同種装備を通常候補から除外します。進化した2攻撃は1攻撃として数えるため、攻撃枠が1つ空きます。

対象選択は全攻撃を最寄り敵へ統一せず、役割に応じて使い分けます。Railなどは最寄り、Vector／Laser／Harpoonはボス・高HP、Mortar／Gravity／Skyfall／Needleは密集地点、Mirage／Pylon／Ricochetなどは対象分散を使います。

## Tier 3進化

次の6組は、両方をTier 3へ上げるとボス報酬の「改造」で進化できます。

| ペア | 進化名 |
| --- | --- |
| Vector Lance + Ion Lance | ベクター・イオンランス |
| Rico Burst + Arc Link | 跳弾アーク |
| Singularity Shot + Pulse Mortar | 特異点迫撃 |
| Mirage Drone + Sentry Pylon | ミラージュ砲列 |
| Nova Ring + Saw Halo | ノヴァ・ソーハロ |
| Rail Minefield + Decoy Beacon | 誘爆ビーコン |

進化は2攻撃の挙動を統合し、火力だけでなく投射物・アクター数の削減も行います。成立するTier 3ペアがない場合、ボス報酬の改造は無効表示になります。

## 敵、侵入、ボス

敵はScout、Striker、Bulwarkの基本3種です。封鎖壁の外側では`enteringContainment`として高速侵入し、壁内へ到達後に共通戦闘対象になります。壁外の敵を倒して回収不能ドロップを作らないため、侵入中は攻撃対象外です。

| 敵 | 特徴 |
| --- | --- |
| Scout | 基本追跡型。 |
| Striker | 予告線後に高速突進。 |
| Bulwark | 高耐久。衝撃波、突進、砲撃、低HP時の三連砲撃。通常個体だけが撃破時に半径2.6・10ダメージの爆発を持つ。 |
| 高レベル変種 | 機動、装甲、波動、漂流、群体、包囲など21種。Lv40／50／60で各7種解放。 |

Normalの固定ボスは段階ごとにScout、Striker、Bulwarkを基礎に専用HP、サイズ、行動を持ちます。最終ボス撃破時は5,000点のクリアボーナスを加えて`gameover`のClearへ移ります。Endlessは5Lvごとのランダム基礎種ボスを継続します。

## ボス報酬

Normalの3:00／6:00ミッドボスとEndlessの周期ボスを倒すと、`bossReward`で次から1つを選びます。

| 報酬 | 実装効果 |
| --- | --- |
| 修復 | 最大HPの35%を回復。最低28。全回復や最大HP増加ではない。 |
| 増幅 | 全攻撃ダメージ+8%。累積倍率1.48で上限。 |
| 改造 | 条件を満たしたTier 3ペアを進化。成立時だけ選択可能。 |

報酬選択後は選んだ効果だけを適用して戦闘へ戻ります。Normal最終ボスはそのままクリアになるため戦闘報酬を提示しません。

## 経験値とドロップ

Lv50以降は経験値流入と回復・マグネット報酬を抑え、必要経験値を追加成長させます。実行時の経験値倍率はLv30で1.45、Lv40で1.90、Lv50で1.20、Lv60で1.00です。

回復アイテムとマグネットは敵撃破時に確率で生成され、寿命が近づくと点滅して消滅します。マグネットはフィールド上の経験値ジェムを一括回収します。詳細値は[高レベル帯バランス報告](../high_level_balance_report.md)と[高レベル変種パラメータ](../high_level_variant_parameters.md)を参照してください。

## スコア、コンボ、ローカルベスト

撃破時に敵種別の基礎点へコンボ倍率を掛けます。コンボ猶予は3秒で、撃破により更新し、被弾で0へ戻ります。5／15／30／50コンボで1.25／1.5／1.75／2.0倍へ上がります。ボス単独戦では猶予を停止し、ボスHPを10%削るごとに5コンボを加えます。

基礎点はScout 100、Striker 150、Bulwark 350、変種`150 + 35 × 基礎XP`、ミッドボス3,000、最終ボス10,000です。HP25%以下で敵を倒すと危険撃破ボーナス+200、Perfect Dodgeで+200、Normalクリアで+5,000を得ます。Normalクリア時だけ`最終Lv × 100 + 残HP × 10`を加えます。

NormalとEndlessのベストスコアはブラウザへ別々に保存します。オンラインランキングは未実装です。

## リザルト

リザルトはClear、Failed、Retiredを区別し、次を表示します。

- スコア、生存時間、総撃破数、最終レベル。
- 現在コンボ、最大コンボ、Perfect Dodge数、ボス撃破数。
- 失敗・撤退理由、Dodge強化残り時間、進化済み武器。
- 装備別Tier、実与ダメージ、最終撃破数。
- 選択モードのローカルベスト。

同じモードへ再挑戦するか、タイトルへ戻って名前・モードを選び直せます。新しいランでは戦闘統計、スコア、コンボ、ボス、進化状態を初期化します。

## 音、設定、モバイル表示

効果音はWeb Audio APIのOscillatorとGainで短い合成音を生成し、ボス出現と選択操作にはCC0素材を同じAudioContextの時計へ重ねます。素材は`client/public/audio`へ同梱し、外部サイトへ接続しません。素材の出典、ハッシュ、読み込み中の合成音フォールバック、同期方法は[AUDIO_CREDITS.md](AUDIO_CREDITS.md)に記録しています。ブラウザの自動再生制限に従い、ユーザー操作後にAudioContextを開始します。効果音のオン／オフは端末へ保存します。

設定ではフローティングスティック透明度20〜100%、カメラ倍率82〜122%、効果音を変更できます。出撃中にSettingsを開くと`paused`になり、閉じると元のPause経路に応じて再開します。

HTML viewportは`viewport-fit=cover`を指定し、HUDは`env(safe-area-inset-*)`を使ってノッチ、角丸、ホームインジケーターを避けます。表示領域の実寸と縦横比に応じてカメラとHUD密度を切り替えます。
