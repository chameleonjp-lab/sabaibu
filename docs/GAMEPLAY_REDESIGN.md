# ゲームプレイ再設計方針

## 文書の位置づけ

本書は、現行の `client/src/game/GameWorld.ts` にある進行、スポーン、経験値、装備、ボス、停止ペナルティ、リザルトを基準に、通常モード（Normal）とエンドレスモード（Endless）を分離するための実装方針を定めます。ここに記載する項目は再設計の目標値であり、現行コードがすでにすべてを実装していることを意味しません。

ランキング、オンラインリーダーボード、シーズン集計は本再設計の対象外とし、ゲーム内スコアが安定してから別途判断します。

## モード構成と制限時間

### Normal

Normalの目標は、**10:00のアクティブ戦闘時間**でひとつのビルドを完成させ、最終ボスへ到達することです。アップグレード選択中は現行と同様に世界と戦闘時計を停止します。

| 時刻 | イベント |
| --- | --- |
| 0:00 | 通常戦闘開始。 |
| 3:00 | 固定ミッドボス1。専用戦闘中は通常生成を止め、召喚行動で増援を管理する。 |
| 6:00 | 固定ミッドボス2。専用戦闘中は通常生成を止める。 |
| 9:15 | 最終ボス。通常敵の新規生成を停止し、30〜45秒の討伐時間を目標に調整する。 |
| 10:00 | Normalの終了時刻。最終ボス撃破済みならCLEAR、未撃破ならFAILEDとする。 |

### 6分・8分を採用しない理由

現行の経験値要求、敵種別XP、スポーン間隔、5Lvごとのボスによる1Lv上昇を使い、敵を即時撃破して全XPを回収する上限条件では、6:00時点がおよそLv33、8:00時点がおよそLv44、10:00時点がおよそLv57です。撃破・回収効率を85%程度とすると、およそLv29、Lv38、Lv48まで下がります。

- 6:00では、Lv30から始まる現行の追加モジュール成長へ到達した直後、または到達前に終わります。
- 8:00では、上限条件でもLv40変種を遊べる時間が短く、通常プレイではLv40へ届かない可能性があります。
- 10:00ならLv30以降の成長を複数回経験し、Lv40変種を実戦で扱う時間を確保できます。強いランだけがLv50帯へ触れる構造もNormalの上振れとして利用できます。

このため、現行曲線を全面的に圧縮しない限り、Normalは10:00を採用します。Lv60以降はNormalの必須到達点にしません。

### Endless

Endlessは現行のレベル駆動型長期生存を引き継ぎます。Lv40、Lv50、Lv60で各セットの高レベル変種を解放し、長時間ビルドと敵圧の限界を試すモードにします。Normalの固定ボス時刻、10:00終了、Normal用の変種出現上限は適用しません。ただし、メッシュ数やドロップ数の安全上限はEndlessにも必要です。

## Normalの敵生成上限

Normalでは、火力不足を敵メッシュ数だけで表現しません。

| 項目 | Normal上限 |
| --- | ---: |
| 同時通常敵数 | 56体 |
| 平均生成速度 | 4.0体/秒 |
| 1回の生成数 | 最大2体 |
| 未回収XPジェム | 100メッシュ |
| 同時ボス | 1体 |

XPジェムが100メッシュを超える場合は、最古または近接するジェムへXP値を統合し、取得可能な総XPを失わせずにメッシュ数を減らします。高レベル変種の波動も無制限に重ねず、直接ダメージを持つ波動変種は同時3体をNormalの目安とします。

現行のLv50帯は最大82体・6.0体/秒、Lv60帯は最大94体・約6.82体/秒へ上がります。この値をNormalへそのまま持ち込むと、敵本体、子メッシュ、オーラ、警告、投射物、寿命を持たないXPジェムが重なり、特にモバイルで描画負荷と視認性が破綻する可能性が高いため採用しません。

## 装備枠と成長

Normalの装備は次の2系統へ分離します。

| 枠 | 上限 | 数え方 |
| --- | ---: | --- |
| 攻撃枠 | 6 | 初期装備のRail Pulseを含む。Scatter、Orbit、攻撃モジュールを数える。 |
| ユーティリティ枠 | 4 | Barrier、Relay、Reactive、Cryo、Corrosionなど、独立した攻撃射出を主目的にしない強化を数える。 |

現行のLv30以降7Lvごとの攻撃枠増加はNormalでは使いません。攻撃枠が埋まった後は、新規攻撃を通常候補から外し、所持攻撃のTier上昇、ユーティリティ、進化を優先します。ScatterとOrbitを含む攻撃はTier 3を通常上限とします。進化で2つの攻撃が1つへ置き換わった場合は攻撃枠を1枠空けます。

Endlessで7枠目以降を解放するかは、10:00以降の性能測定を行ってから決めます。

## 停止針と回避行動

2秒停止後に落下し50ダメージを与える現行の停止針は、通常のNormalおよびEndlessから削除します。停止針は `?idle` などのデバッグ・演出確認経路だけに残します。設定画面、タッチ入力の持ち替え、アクセシビリティ上の停止を即死級のペナルティへ結びつけないためです。

通常プレイには代わりに能動回避を追加します。

- 回避クールダウンは**4.2秒**。
- 移動入力方向へ短距離移動し、警告攻撃を抜ける用途に限定します。
- 回避距離は3.4、無敵時間は0.28秒、予告攻撃に対する完全回避の受付は0.34秒です。移動で当たり判定そのものを抜けた場合も、予告終了直前なら完全回避として記録します。
- アップグレード、設定、ページ非表示中はクールダウンを進めず、誤入力で発動させません。

## ボスと報酬

Normalのミッドボスはレベル到達ではなく3:00と6:00に固定します。最終ボスは9:15に固定します。専用ボスが完成するまでは、全攻撃行動を持つBulwark系を基礎にし、巨大ScoutのようにHPだけが高く行動が少ない個体をランダム生成しません。

ミッドボス討伐後は、次の報酬から1つを選びます。

| 報酬 | 効果 |
| --- | --- |
| REPAIR | 最大HPの35%（最低28）を回復する。過剰回復で最大HPは増えない。 |
| AMPLIFY | 全攻撃を8%増幅する。累積倍率1.48を上限とする。 |
| EVOLVE | 条件を満たしたTier 3ペアを進化させ、2攻撃を1攻撃へ置換して1枠空ける。 |

EVOLVEの成立候補がない場合は条件不足を明示して無効表示にします。旧仕様の「最大HP+3、全回復、1Lv上昇、さらに通常強化」の同時付与は、回復と成長を一度に与えすぎるため廃止します。最終ボス後は戦闘が終了するため、戦闘性能報酬は与えません。

## Tier 3進化レシピ

初期実装は次の6レシピに限定します。両方の攻撃がTier 3であることと、ミッドボス報酬でEVOLVEを選ぶことを条件にします。

| Tier 3ペア | 進化後の役割 | 実装上の制約 |
| --- | --- | --- |
| Vector Lance + Ion Lance | ボス向け貫通レール | 発射物を増やさず、一本の高出力射線へ統合する。 |
| Rico Burst + Arc Link | 群体向け連鎖オーブ | 連鎖数に上限を置き、跳弾と電撃を別々に大量生成しない。 |
| Singularity Shot + Pulse Mortar | 集敵後の集中砲撃 | 重力コア1個と終端砲撃へ統合する。 |
| Mirage Drone + Sentry Pylon | 移動砲台編隊 | 同時稼働アクターは最大3体。 |
| Nova Ring + Saw Halo | 常設近接防衛環 | 常時判定を1系統へまとめ、鋸と衝撃波の重複生成を抑える。 |
| Rail Minefield + Decoy Beacon | 誘導式キルゾーン | 設置物は最大3個。上書き時は消去せず縮小起爆する。 |

進化後の実戦DPSは、元の2攻撃の実効合計に対して約1.15〜1.30倍を初期目標とします。理論上すべての弾・連鎖・範囲が命中した上限値同士を加算しません。進化は火力上昇だけでなく、投射物やアクターを統合してモバイル負荷を下げる役割も持たせます。

## スコアとコンボ

スコアは撃破を基準にし、総与ダメージを直接スコアへ変換しません。現行の与ダメージ集計は装備別テレメトリーとしてリザルトへ残します。

### 基礎撃破スコア

| 敵 | 基礎点 |
| --- | ---: |
| Scout | 100 |
| Striker | 150 |
| Bulwark | 350 |
| 高レベル変種 | `150 + 35 × 変種XP基礎値` |
| ミッドボス | 3,000 |
| 最終ボス | 10,000 |

### コンボ

- 敵撃破でコンボを1増やし、猶予を3.0秒へ戻します。
- プレイヤー被弾でコンボを0へ戻します。
- 5 / 15 / 30 / 50コンボで倍率を1.25 / 1.50 / 1.75 / 2.00倍へ上げ、2.00倍を上限とします。
- ボス単独フェーズではコンボ猶予を停止し、ボス最大HPを10%削るごとにコンボを5加算します。
- Normalクリア時は5,000点、さらに`最終レベル × 100 + 残HP × 10`を加算します。

高密度帯では撃破間隔だけを条件にすると最大倍率が自動維持されやすいため、被弾リセットを主要な技量条件にします。

## ランキング

オンラインランキング、フレンド順位、シーズン、チート対策、リプレイ検証は**延期**します。まずローカルのスコア計算、同一バージョン内の再現性、Normal完走率、武器別スコア偏差を検証します。ランキング仕様を確定するまで、スコアはローカルのリザルト表示に限定します。

## 残る調整リスク

1. **最終ボスの制限時間:** 9:15出現から10:00までの45秒で、弱いビルドと強いビルドの双方に成立するHPを実測する必要があります。
2. **経験値効率差:** ジェム回収率が低いプレイヤーは10:00でもLv40へ届かない可能性があります。ジェム統合後の回収率を測定します。
3. **進化候補の再現性:** 25モジュールの大きな抽選母集団では、意図したTier 3ペアが揃わない可能性があります。最初の構成要素取得後に相方を適度に重み付けする必要があります。
4. **単体DPSと群体DPSの格差:** Ricochet、Chain、Splitなどの理論群体DPSを、そのままボスHPや進化倍率へ使えません。単体・5体・密集20体の3条件で測定します。
5. **警告の視認性:** 56体、オーラ、設置物、コンボ表示の中で、Striker、Bulwark、最終ボスの赤い警告がモバイルでも読めるか確認します。
6. **メッシュ生成GC:** 敵数を抑えても、投射物、衝撃波、エネルギートレースを毎回生成・破棄する現行方式は長時間プレイで負荷になり得ます。プール化の要否を測定します。
7. **ユーティリティ枠の分類:** Reactiveは反撃ダメージを持つため、攻撃枠かユーティリティ枠かで実効火力が変わります。初期方針はユーティリティですが、選択率とDPSを監視します。
8. **NormalとEndlessの分岐:** 共通定数を直接変更するとEndlessのLv40/50/60曲線を壊します。モード別スポーンプロファイルと終了条件を分離する必要があります。
