# サバサバ

**Amberline Cataclysm** の封鎖都市を舞台にした、ブラウザ向け見下ろし型3Dサバイバルアクションです。プレイヤーは自動攻撃を軸に敵群を迎撃し、経験値による成長、装備選択、回避、ボス報酬を組み合わせてNormalの固定任務またはEndlessの長期生存へ挑みます。

React 19、TypeScript、Vite、Babylon.jsで構成し、デスクトップとスマートフォンの縦横画面に対応します。

## ゲームを始める

ローカル環境では、依存関係を導入して開発サーバーを起動します。

```bash
pnpm install
pnpm dev
```

開発中は次の品質チェックを実行します。

```bash
pnpm check
pnpm test:rules
pnpm build
```

| 項目 | 内容 |
| --- | --- |
| 目的 | 自動攻撃・敵群・ランダム強化・生存を組み合わせた3Dサバイバルアクション。 |
| 出撃開始 | 開始画面でプレイヤー名を入力し、NormalまたはEndlessを選択。名前、設定、モード別ベストスコアは端末へ保存。 |
| 主要ループ | 敵を撃破 → 経験値とドロップを回収 → レベルアップ選択 → ビルドを拡張 → 編成ウェーブとボスへ対応。 |
| Normal | 10:00で完結する固定任務。3:00と6:00にミッドボス、9:15に最終ボスが出現し、時間内の最終ボス撃破でクリア。 |
| Endless | 終了時刻を持たない長期生存。5Lvごとの巨大ボスとLv40／50／60の高レベル変種が継続。 |
| 勝敗 | 体力0、またはNormalで10:00までに最終ボスを倒せないと失敗。Normal最終ボス撃破でクリア。任意撤退にも対応し、拡張リザルトから同モード再挑戦またはタイトルへ戻れる。 |
| 想定環境 | 最新のデスクトップ／モバイルブラウザ。スマートフォンは縦横の画面比率とセーフエリアに合わせてHUDとカメラを調整。 |

## ゲームシステム

### 戦闘と敵

敵は封鎖壁の外側から侵入し、戦闘領域に入るまで侵入演出状態を維持します。壁内へ到達した敵だけが共通の対象判定を通り、標準武器と全モジュールから命中可能になります。

| 敵 | 特徴 |
| --- | --- |
| Scout | 基本となる追跡型。数で圧力を作る。 |
| Striker | 予告後に突進する高速型。移動継続と位置取りを要求する。 |
| Bulwark | 高耐久の重装ボス。赤系の衝撃波、突進、範囲砲撃、低耐久時の三連砲撃を使う。近距離で倒すと、実寸表示された半径2.6内でのみ10の爆発ダメージを受ける。 |
| 高レベル変種 | Lv40、Lv50、Lv60で各7種を追加。機動、装甲、波動、漂流、群体、包囲を中心に、完成ビルドでも位置取りを要求する。 |

> 敵の凍結・腐食・デコイ型は採用していません。クライオロック、腐食刻印、デコイビーコンはプレイヤー専用のモジュールとして保持します。

### 武器、モジュール、成長

初期攻撃は**レールパルス**です。散弾アレイ、周回センチネルと25種のモジュールはランダムな3択から取得し、攻撃は原則Tier 3まで強化できます。1ランにつき3回まで候補を再抽選できます。

| 分類 | 主な装備 |
| --- | --- |
| 貫通・射撃 | ベクターランス、跳弾バースト、迫撃アーク、プリズム分裂、イオンランス、ニードルレイン、クラスターコア。 |
| 範囲・近接 | ノヴァリング、リターンブレード、近接地雷、プリズム扇撃、位相クリーヴァー、ソーハロ、ソニックブレイカー。 |
| 追尾・連鎖 | ミラージュドローン、アーク連鎖、サーマルアーク、チェーンハープーン。 |
| 設置・制御 | セントリーパイロン、特異点弾、デコイビーコン、スカイフォール標識。 |
| 防御・状態 | リアクティブ装甲、クライオロック、腐食刻印。 |

装備上限は**攻撃6枠（初期Railを含む）**と**補助4枠**です。攻撃枠が埋まると新規攻撃を候補から外し、所持装備の強化を優先します。補助枠にはRelay、Reactive、Cryo、Corrosionが入り、BarrierはEndlessだけで候補になります。Normalでは通常のレベルアップから耐久上限を増やさず、耐久強化はボス報酬で選びます。進化で2つの攻撃を統合すると攻撃枠が1つ空きます。

実装済みのTier 3進化は、Vector + Laser、Ricochet + Chain、Gravity + Mortar、Mirage + Pylon、Nova + Saw、Mine + Decoyの6組です。対応ペアを両方Tier 3へ上げた時点で自動進化し、ボス報酬の選択枠は使いません。

### モード別ボス、報酬、長期戦

Normalでは3:00に侵入母艦、6:00に突撃指揮機、9:15に重装破城機が出現します。ボス出現時も既存の通常敵を残し、新規生成だけを止めます。最終ボス撃破で任務をクリアします。Endlessでは従来どおり5LvごとにScout、Striker、Bulwarkを基礎とする巨大ボスが出現します。

ミッドボスとEndlessの周期ボス討伐後は`bossReward`へ移り、**攻撃強化**（全攻撃ダメージ+4%）または**耐久強化**（最大耐久+5、現在耐久も5回復）の2択から1つを選びます。

通常の敵は回復アイテムとマグネットを確率で落とします。Lv50以降は成長速度と回復過多を防ぐため、経験値倍率・マグネット・回復ドロップ・回復量を抑制し、必要経験値を追加で伸ばします。

| レベル帯 | 経験値倍率 | 回復ドロップ | マグネット | 回復量 |
| --- | ---: | ---: | ---: | ---: |
| Lv1〜29 | 1.00倍 | 6.0% | 2.17% | 最大HPの22.0% |
| Lv30〜39 | 1.45倍 | 7.2% | 2.9% | 最大HPの23.5% |
| Lv40〜49 | 1.90倍 | 8.4% | 3.7% | 最大HPの25.0% |
| Lv50〜59 | 1.20倍 | 3.4% | 2.7% | 最大HPの21.5% |
| Lv60以降 | 1.00倍 | 2.8% | 2.2% | 最大HPの20.0% |

### リザルトと戦闘統計

撃破ごとの基礎点と3秒コンボでスコアを算出し、被弾でコンボをリセットします。HP25%以下での撃破は危険撃破ボーナス+200です。モード別ベストスコアはローカルストレージへ保存し、結果確定時にNormal／Endless別の共通ランキングへ1回だけ送信します。上位10件を結果画面へ表示し、通信失敗時は同じ画面から再送できます。確認用URLの結果プレビューやデバッグ表示はランキングへ送信しません。

戦闘終了後の拡張リザルトでは、結果、スコア、生存時間、総撃破数、最終レベル、コンボ、最大コンボ、Perfect Dodge、ボス撃破数、死因、進化装備、モード別ベストと、取得済み武器・モジュールごとの**実与ダメージ**・**最終撃破数**を表示します。投射物、設置物、範囲攻撃、状態異常、反撃波などの遅延攻撃も発生源を維持して集計します。

詳細な仕様は [ゲームシステム資料](docs/GAMEPLAY_SYSTEMS.md) を参照してください。

## 操作方法とモバイル対応

| 環境 | 操作 |
| --- | --- |
| デスクトップ | `WASD` または矢印キーで移動。`Space`でDodge、`P`で一時停止。移動方向はカメラ基準で補正し、攻撃は自動。 |
| スマートフォン | 画面内の任意位置をタップするとフローティング仮想スティックが出現。ドラッグで移動し、画面上の`DODGE`ボタンで回避。指を離す・キャンセルする・ポインター捕捉を失うと移動と表示を解除。 |
| 武器レール | 画面下部のレールを左右へスワイプすると、画面に収まらない取得済み武器・モジュールを確認可能。ネイティブ横スクロール、スナップ、端部フェードを利用。 |

Dodgeは120秒クールダウン、3.4の移動、0.28秒の無敵を持ちます。予告終了直前0.34秒に危険範囲から実際に抜ける回避、または無敵中の被弾判定でPerfect Dodgeとなり、短時間の攻撃強化を得ます。1秒間停止すると、予告後に落下針が降ります。

HUDは縦長、標準縦、横長、コンパクト横の表示領域で密度を切り替えます。`viewport-fit=cover`と`env(safe-area-inset-*)`を使い、ノッチやホームインジケーターを避けます。PAUSEまたはSETTINGSを開いている間は`paused`となり、戦闘と時計を停止します。設定ではスティック透明度、カメラ倍率、合成音と同じ時計へ重ねるCC0効果音のオン／オフを保存できます。カメラ倍率は表示だけに作用し、攻撃射程や敵生成速度は変わりません。音素材の出典は[音素材の出典](docs/AUDIO_CREDITS.md)に記録しています。

## 確認用URL

各URLは通常プレイを変更せず、対象機能を再現・表示するための確認シナリオです。複数のパラメータは `&` で組み合わせられます。

| URLパラメータ | 用途 |
| --- | --- |
| `?demo` | 自動戦闘デモ。 |
| `?boss` / `?striker` | Bulwarkの通常行動、Strikerの予告・突進を確認。 |
| `?idle` | 通常プレイでは無効な旧停止針をデバッグ限定で確認。 |
| `?explosion` | 通常敵撃破で爆発ダメージが発生しないことを確認。 |
| `?bossExplosion` / `?bossExplosionFar` | Bulwark近距離撃破の10ダメージと、遠距離撃破時の無被弾を確認。 |
| `?debug` | 実験場。壁内外数、発射、衝突、命中、撃破、侵入、被弾原因に加え、メッシュ数・一時エフェクト数・ドロップ数・音声キュー数の現在値とピーク値を表示。 |
| `?level=30` / `?level=31` / `?level=37` / `?level=44` | 高レベルのアップグレード候補と装備上限を確認。 |
| `?balance=30` / `?balance=40` / `?balance=50` / `?balance=60` | 高レベル帯の密度、経験値、ドロップ曲線をHUDで確認。 |
| `?variants=40` / `?variants=50` / `?variants=60` | 各レベル帯の高レベル敵変種を展示。 |
| `?milestoneBoss=5` | Endlessで継続する5Lv周期の巨大ボスを展示。5の倍数へ変更可能。 |
| `?milestoneReward=5` | 巨大ボス討伐後の選択式報酬（修復／増幅／進化）を確認。 |
| `?obstacle` | 障害物中心からプレイヤーを押し戻す円形衝突判定を確認。 |
| `?result` | 戦闘終了後のリザルト画面と、送信を行わないランキング表示を確認。 |
| `?ranking` | ランキング付きリザルトだけを開く確認用URL。実際のランキング送信は行わない。 |
| `?touch` | フローティング仮想スティックの表示を確認。 |
| `?settings` | スティック透明度・カメラ倍率を調整する設定画面を開く。`?settings&touch`で操作パッドとの併用を確認。 |
| `?audit=<moduleId>` | 任意のモジュールをTier 3の個別監査シナリオで確認。 |

## ライセンスと貢献

現在は継続開発中のプロジェクトです。変更を提案する場合は、対象機能の再現URL、型検査、本番ビルド、必要な画面比率のスクリーンショットを添えてください。GitHub上の変更はレビュー可能なPRとして扱います。

### 検証付きランキングと新しい得点

NormalとEndlessは別ランキングです。同じ名前で遊んでも、プレイ回数と最高得点はモードごとに更新します。開始時にサーバー発行の一度だけ使える識別番号を取得し、Normalは正規クリア、Endlessはゲームオーバー時だけ結果を送ります。送信失敗時は端末へ保存し、次回表示時に再送します。

得点画面では、撃破・時間・レベルの加点と、被弾回数・被ダメージの減点を分けて表示します。

## 現行仕様

現在の実装・仕様・検証の基準は [サバサバ現行仕様書](docs/SABASABA_CURRENT_SPEC.md) です。過去の設計書と異なる場合は、この仕様書を優先します。ランキングはサーバー側の検証が完成するまで無効です。
